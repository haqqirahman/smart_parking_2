# Smart Parking 2

Sistem monitoring dan deteksi slot parkir berbasis YOLO dan PHP.

## Fitur

- Monitoring slot parkir real-time
- Deteksi kendaraan menggunakan YOLO
- Riwayat parkir
- Export laporan PDF
- Dashboard monitoring

## Teknologi

- PHP
- MySQL
- Python
- YOLO
- XAMPP

## Instalasi

1. Clone repository

```bash
git clone <repository-url>
```

2. Import database

```text
car_park_db.sql
```

3. Install dependency PHP

```bash
composer install
```

4. Jalankan XAMPP

- Apache
- MySQL

5. Buka browser

```text
http://localhost/WEB/smart_parking_2
```
